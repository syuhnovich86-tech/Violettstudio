# Violetta Studio / Vita29

Исходный код внутреннего файлового сервера студии на Raspberry Pi.

## Возможности

- общие и приватные папки с настраиваемыми правами;
- загрузка, серийная съёмка, просмотр и системное меню «Поделиться»;
- видео, подготовка превью и загрузка крупных файлов;
- привязка материалов к визитам и календарям YCLIENTS;
- фильтры по клиенту, процедуре, дате, году, месяцу и геометкам;
- комментарии, упоминания, обсуждения и push-уведомления;
- импорт медиатеки iPhone с сохранением даты съёмки и координат;
- адаптивный мобильный интерфейс и PWA.

## Структура

- `backend/` — FastAPI, SQLAlchemy, миграции Alembic и тесты;
- `frontend/` — React/TypeScript/Vite и PWA;
- `deploy/` — Docker Compose, Caddy и серверные утилиты;
- `scripts/` — вспомогательные и обслуживающие скрипты;
- `docs/` — архитектура и инструкции.

## Запуск

1. Скопировать `deploy/env.example` в `deploy/.env` и заполнить параметры.
2. Создать секреты YCLIENTS и VAPID вне репозитория в `/opt/vita29/secrets`.
3. Запустить из `deploy/`: `docker compose up -d --build`.
4. Проверить `GET /api/v1/health`.

Базы данных, фотографии, видео, токены, закрытые ключи и реальные `.env` намеренно не входят в репозиторий.
