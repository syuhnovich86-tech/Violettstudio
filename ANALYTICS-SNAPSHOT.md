# Analytics source snapshot

- API and access control: `backend/src/vita29/api/content_analytics.py`.
- VK, Threads, and subscriber snapshots: `backend/src/vita29/content/vk_analytics.py`, `threads_analytics.py`, and `follower_history.py`.
- Web interface: `frontend/src/main.tsx`, `frontend/src/styles.css`.
- Android interface: `apps/mobile/src/content/AnalyticsPanel.tsx`.
- VK access diagnostic mini-app: `tools/vk-analytics-check/`.

VK Bridge user tokens observed during testing are bound to the client IP: a successful browser check does not demonstrate server access or automatic refresh. Continuous collection requires a separately verified authentication and refresh approach. Do not put tokens in source control.

Mobile native projects are generated by Expo prebuild. Firebase configuration, release signing keys, server configuration, user data and media are intentionally excluded; provide these securely in the build environment.
