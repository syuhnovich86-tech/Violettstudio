# Истории и вертикальные публикации через API

## Telegram

Официальный метод Bot API `postStory` публикует историю **от имени управляемого бизнес-аккаунта**, а не от имени канала. Нужны:

1. бизнес-аккаунт Telegram, подключённый к боту;
2. `business_connection_id` от этого подключения;
3. право бота `can_manage_stories`;
4. вертикальный файл: фото 1080×1920 до 10 МБ либо видео до 60 секунд / 30 МБ в требуемом Telegram формате.

Для этого подготовлен [скрипт](scripts/publish_telegram_business_story.py). Обычный токен бота, добавленного админом в канал, для истории канала недостаточен.

## MAX

В публичной документации MAX есть API для загрузки медиа и публикации в канал (`POST /uploads`, затем `POST /messages`), но отдельного API историй на 4 ноября 2026 года нет. Поэтому автоматический вариант — вертикальный пост в канале. Для него подготовлен [скрипт](scripts/publish_max_channel_post.py).

Скрипты используют переменные окружения, а не записывают токены в код или историю команд.
