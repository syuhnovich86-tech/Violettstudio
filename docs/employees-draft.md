# Предварительный список сотрудников

Источник: публичный сайт студии <https://violettastudio.ru/>. Проверено: 2026-08-14.

Этот список используется только для подготовки проекта. Учётные записи ещё не созданы. Для студии запланировано девять пользователей: два администратора и семь сотрудников. Виолетта Юхнович и администратор Виолетта — два разных человека. Дополнительно будет отдельная защищённая учётная запись владельца системы — заказчика проекта; всего десять учётных записей.

| № | Отображаемое имя | Роль/специализация на сайте | Будущая роль в сервере |
|---:|---|---|---|
| 1 | Виолетта Юхнович | Основатель студии, топ-мастер, наставник | Сотрудник |
| 2 | Кристина | Ведущий мастер перманентного макияжа | Сотрудник |
| 3 | Вероника | Мастер перманентного макияжа | Сотрудник |
| 4 | Светлана (перманент) | Ведущий мастер перманентного и камуфляжного макияжа | Сотрудник |
| 5 | Софья | Мастер перманентного макияжа и тату | Сотрудник |
| 6 | Анастасия | Мастер по пирсингу и депиляции | Сотрудник |
| 7 | Светлана (косметолог) | Косметолог | Сотрудник |
| 8 | Мария | Администратор студии | Администратор |
| 9 | Виолетта (администратор) | Администратор студии; не Виолетта Юхнович | Администратор |

Над администраторами студии находится отдельная роль `owner` — владелец системы. Эта запись принадлежит заказчику, создаётся первой непосредственно на Raspberry Pi и не может быть отключена через веб-интерфейс.
