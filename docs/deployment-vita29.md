# Первое развёртывание на vita29

Дата: 2026-08-14. Статус: приложение запущено в локальной сети и доступно удалённо через Tailscale Funnel с авторизацией самого приложения.

## Состояние

- сервер: `vita29`, Debian 13.6, ARM64;
- адрес: <http://192.168.1.212:8080>;
- публичный HTTPS-вход с авторизацией приложения: <https://vita29.taild51e5c.ts.net/>;
- Docker 26.1.5 и Docker Compose 2.26.1 установлены из официального репозитория Debian;
- контейнеры `app` и `caddy` запущены с автоперезапуском;
- healthcheck базы и хранилища проходит;
- приложение проверено после перезапуска;
- код: `/opt/vita29`;
- SQLite: `/srv/vita29/app-data/vita29.db`;
- оригиналы: `/srv/vita29/media/originals`;
- корзина: `/srv/vita29/media/.trash`;
- порт приложения напрямую не опубликован, локально открыт только Caddy на `8080`;
- Tailscale 1.102.2 установлен как системная служба и автоматически запускается после перезагрузки;
- Tailscale Funnel проксирует публичный HTTPS-вход на локальный Caddy `127.0.0.1:8080`;
- наружу доступна форма входа, а папки и файлы требуют действующую сессию приложения;
- session cookie имеет флаги `Secure`, `HttpOnly` и `SameSite=Lax`;
- Caddy добавляет HSTS, CSP, запрет встраивания во фреймы и другие защитные заголовки;
- перебор пароля ограничен пятью неудачными попытками за пять минут для каждого логина.
- каждый пользователь может сменить собственный пароль после входа;
- фото и видео можно переносить между доступными папками без потери приватных ограничений.

## Закрытый удалённый доступ

Сотрудник открывает <https://vita29.taild51e5c.ts.net/> в обычном браузере и авторизуется своей учётной записью приложения; устанавливать Tailscale на телефон не требуется. Файлы физически остаются на Raspberry Pi, а передача выполняется по HTTPS.

## Создание владельца

Команда запускается из Windows PowerShell. Она интерактивно просит новый пароль приложения дважды:

```powershell
ssh -t -i "$env:USERPROFILE\.ssh\vita29_codex" stepan@192.168.1.212 "cd /opt/vita29/deploy && sudo docker compose exec app python -m vita29.cli create-owner --name 'Степан' --login stepan"
```

После создания владелец входит по адресу <http://192.168.1.212:8080> и создаёт Марию и Виолетту с ролью администратора. Администраторы студии затем могут создавать сотрудников.
