# Файловые операции v1

Контрольная точка этапа 3 завершена 2026-08-14.

## Реализовано

- пакетная загрузка фото и видео из мобильной галереи;
- отдельная кнопка камеры с `capture=environment` для поддерживающих браузеров;
- потоковое копирование частями по 1 МиБ;
- лимит одного файла 2 ГиБ, настраиваемый через окружение;
- проверка свободного места с сохранением аварийного резерва;
- определение типа по содержимому, а не только по имени файла;
- JPEG, PNG, GIF, WebP, HEIC/HEIF, AVIF, MP4 и QuickTime/MOV;
- UUID вместо пользовательского имени в физическом пути;
- SHA-256 каждого оригинала;
- отдельная галерея каждой рабочей папки и переключение между папками сотрудников без смешивания файлов в общий поток;
- приватные папки с серверной проверкой списка участников для списка, превью, миниатюры и скачивания;
- загрузка в папку любого активного сотрудника;
- перенос фото и видео между всеми доступными пользователю папками с физическим перемещением оригинала и записью в аудит;
- миниатюры, полноэкранный просмотр фото со свайпами, стрелками и счётчиком, а также встроенное воспроизведение видео;
- скачивание и системное меню «Поделиться» в безопасном HTTPS-контексте;
- мягкое удаление в служебную корзину с защитой: сотрудник удаляет только файлы своей папки или загруженные им файлы;
- аудит загрузок, скачиваний, удалений, входов и административных изменений.

Все вошедшие сотрудники могут просматривать, скачивать и переносить файлы между обычными рабочими папками друг друга. Приватные папки доступны только приглашённым участникам; остальные пользователи не могут выбрать их как папку назначения и получают ответ «не найдено» даже по прямой ссылке. В интерфейсе приватная папка отмечена замком.

На локальном HTTP при отсутствии Web Share API кнопка «Поделиться» скачивает файл и объясняет, как отправить его из галереи телефона. Прямой выбор установленных приложений проверяется после включения HTTPS. Восстановление из корзины и её автоматическая очистка остаются отдельным этапом.
