# Черновик обращения в поддержку VK

Здравствуйте! Нужна официальная возможность регулярно собирать статистику сообщества из серверного приложения.

Администратор сообщества предоставил права `stats` и `groups`. В мини-приложении VK запрос `stats.get` возвращает данные. Попытка использовать выданный VK Bridge пользовательский токен на сервере отклоняется с ошибкой 5: токен выдан для другого IP-адреса.

Мы также проверили вход через VK ID с PKCE для веб-приложения Violettacontent (ID 54886080): обновление токена прошло успешно, однако запрос статистики `stats.get` с сервера возвращает ошибку 1051 как до, так и после обновления. Мини-приложение Violetta Analytics имеет ID 54886089.

Подскажите, пожалуйста:
1. Поддерживает ли VK автоматический фоновый сбор статистики сообщества методом `stats.get` с сервера без присутствия администратора?
2. Какой тип приложения, токена, набор прав и способ авторизации для этого предусмотрены? Какие требования к IP-адресам и обновлению токена?
3. Что означает ошибка 1051 в этом сценарии и можно ли получить доступ для приложения Violettacontent?
4. Если фоновый сбор недоступен, какой официальный способ обновлять статистику по запросу администратора вы рекомендуете?

Токены и секретные ключи в обращение не включены.
